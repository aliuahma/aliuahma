Transformers have become ubiquitous in deep learning for their expressivity and practical effectiveneses. However, they suffer from quadratic computational complexity and linear memory complexity w.r.t. the sequence length. In this blog, we focus on linear attention , a form of recurrent architecture. We will start with motivations and build up to modern practices.

Our standard attention is

\[\text{Attention}(Q, K, V) = \text{softmax}(\frac{QK^\top}{\sqrt{d}})V.\]

Traditional linear attention methods seek to approximate the softmax kernel with another similarity measure, $\phi(x)$. By applying this feature map to $Q$ and $K$ respectively, we can define a new similarity score using their inner product:

\[\text{sim}(Q, K) = \langle\phi(Q), \phi(K)\rangle\]
